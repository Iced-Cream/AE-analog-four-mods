# stock/

Put the official Analog Four / Analog Keys MK1 **OS 1.56** firmware here, as

    stock/Analog-Four_Analog-Keys_OS1.56.syx

Download it from Elektron's website (Analog Four MK1 / Analog Keys support pages).
It is Elektron's file, so it is not included. The build checks it against
`SHA256SUMS` and stops if it is a different file.
